# 泰语 1000 词｜卡片式学习工具

一个面向中文学习者的泰语词汇学习网站：把单词、中文释义、真实例句、整句翻译和逐词拆解放在同一张卡片里，打开网页就能开始学习。

## 立即使用

👉 **[点击打开泰语词汇学习网站](https://kinniuroudong-glitch.github.io/thai-vocabulary-studio/)**

无需安装软件、无需注册账号、无需填写 API Key。手机和电脑都可以直接打开：

- **手机**：点击上面的链接，用 Safari 或 Chrome 打开；也可以在浏览器菜单中选择“添加到主屏幕”。
- **电脑**：用 Chrome、Safari 或 Edge 打开链接即可。
- **页面显示旧内容**：下拉刷新，或关闭页面后重新打开链接。

## 这个项目有什么优势？

### 1. 一张卡片真正理解一个词

每张卡片同时展示：

- 泰语单词和中文释义
- 自然、完整的泰语例句
- 整句中文翻译
- 逐词中文拆解
- 单词、例句和逐词内容的点读入口

学习时不需要在词典、翻译软件和例句页面之间来回切换，减少记忆断层。

### 2. 更适合中文学习者

内容按照“泰语 → 中文释义 → 语境例句 → 逐词理解”的顺序组织，适合已经掌握基础泰语、希望扩大词汇量并提高阅读理解能力的学习者。

词库覆盖日常交流、工作沟通、社会生活、抽象表达和较正式的书面词汇，整体面向 B1–C1 进阶学习场景。它是学习辅助工具，不等同于官方 CEFR 等级认证；如果要达到真正的 C1，还需要同步训练听力、语法、写作和真实交流。

### 3. 手机版交互简单直接

- 直接点击泰语单词即可朗读，不需要寻找麦克风按钮。
- 点击卡片左侧或右侧切换前后单词。
- 左右滑动卡片也可以翻页。
- 输入单词编号并确认，可直接跳转到指定词。
- 当前网站在手机端会隐藏重复的麦克风入口，让主要动作更自然。

### 4. 电脑端也有快捷操作

- 鼠标滚轮：切换前后单词。
- 键盘左右方向键：翻页。
- 空格键：朗读当前单词。
- 鼠标中键：朗读当前例句。
- 点击例句或逐词拆解内容：朗读对应泰语片段。

### 5. 分项目学习，不容易失控

词库会自动按每 1000 个单词分成一个学习项目，并提供：

- 项目选择
- 当前词序号跳转
- 项目完成勾选
- 当前学习位置保存

完成一个项目后再进入下一个项目，比一次性面对大量词汇更容易坚持。

目前共收录 **10,689 个词条**，分为 11 个学习项目，最后一个项目包含剩余词条。

### 6. 轻量、隐私友好、跨平台

- 纯网页打开，不需要安装客户端。
- 发音优先调用设备或浏览器的泰语系统语音。
- 不需要 OpenAI API Key，也不会把学习内容上传给语音服务。
- 学习进度保存在当前浏览器本地；更换设备或清除浏览器数据后，进度不会自动同步。

## 推荐学习方法

1. 每天学习 20–40 个新词。
2. 先看泰语单词和例句，尝试自己理解。
3. 点击单词或例句听发音。
4. 再看中文释义和逐词拆解。
5. 用自己的话复述例句，隔天回顾前一天内容。
6. 完成一个项目后，结合泰语视频、新闻或真实对话巩固。
